# Materials Science ML Project

An end-to-end machine learning pipeline for materials science applications, from open-source data to a web-accessible frontend.

## Overview

This project demonstrates the full workflow of a machine learning project applied to materials science:

- **Data Acquisition:** Utilizes an open-source dataset related to material properties.
- **ML Pipeline:** Standardized pipeline including data analysis, cleaning, feature engineering, model selection, and hyperparameter tuning.
- **Deployment:** Converts the trained ML model into a web application using Next.js and React.js for easy access and visualization.

The goal is to provide a reproducible workflow where users can interact with an ML model predicting material properties directly through a user-friendly frontend.
